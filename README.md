#  Free Online Menu Builder

**Create beautiful digital menus for your restaurant, café, bakery or food business — completely free.**

Free Online Menu Builder is a web-based platform that allows food businesses to create, customize and share professional digital menus without needing technical skills or building a website from scratch.

Restaurant owners can manage their food items, upload photos, organize categories, generate QR codes and receive customer orders directly through WhatsApp.

## ✨ Features

- **Restaurant Dashboard** – Manage your digital menu from one place.
- **Menu Builder** – Add, edit and delete food items.
- **Food Categories** – Organize menus into categories such as breakfast, lunch, drinks and desserts.
- **Food Images** – Upload photos to showcase your dishes.
- **Custom Pricing** – Set and update item prices whenever needed.
- **Public Menu Links** – Give every restaurant its own shareable digital menu URL.
- **QR Code Generator** – Generate QR codes that customers can scan to access menus.
- **WhatsApp Ordering** – Allow customers to send orders directly to restaurants.
- **Mobile-Friendly Design** – Menus work across smartphones, tablets and computers.
- **Availability Management** – Mark food items as available or unavailable.

## 🎯 Our Mission

To make digital menus accessible to every food business, especially small and growing businesses that cannot afford expensive website development or restaurant management software.

## 🚀 Getting Started

### Requirements

- PHP 8.0 or later
- MySQL 5.7+ or compatible MariaDB
- Apache server
- Laragon, XAMPP or equivalent local development environment
- Modern web browser

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   ```

2. Move the project into your local server directory.

3. Create a MySQL database for the application.

4. Import the provided database SQL file.

5. Configure your database connection settings.

6. Start Apache and MySQL.

7. Open the application in your browser:

   ```text
   http://localhost/YOUR_PROJECT/
   ```

## 📱 How It Works

1. Register a restaurant account.
2. Set up your restaurant profile.
3. Add food categories and menu items.
4. Upload food photos and set prices.
5. Publish your digital menu.
6. Generate and share your QR code.
7. Receive customer orders through WhatsApp.
